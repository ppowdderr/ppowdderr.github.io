# v19 — The Gate of Ivory

In the old myth, false dreams pass into the waking world through a gate of sawn ivory. Here the whole blog is that gate: two vast carved doors lean apart at the top of the page around a seam of spectral light, and the seam runs on down through the index, where each essay is a dream held under a numbered seal — a slug-turned sigil ring that rotates half a turn when you reach for it. Passing through opens the dream itself: ivory prose on abyss-dark mist, a spectral drop cap, and a quiet line where the dream lets you go.

Zero dependencies: static HTML, one stylesheet, one script, system fonts only. Same post model as the root site — add a file to `posts/` and one line to `postFiles` in `blog.js`.

Sigil motion is disabled under `prefers-reduced-motion`.
