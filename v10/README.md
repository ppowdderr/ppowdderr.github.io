# v10 — Card Catalogue

The index is an open library drawer: each essay is a ruled index card — red top rule, faint blue ruling behind the prose, a punched hole at the foot — threaded on a brass rod that runs the length of the page. Cards carry shelfmark call numbers (`LIF 2026.05.12 · card 3/3`) and `see:` cross-references. Old pattern: the card catalogue. New pattern: CSS-generated ruling aligned to the line-height grid.
