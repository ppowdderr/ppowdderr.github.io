# v11 — Palimpsest

The index is layered vellum: the newest essay sits at the surface in full strength, and each older layer beneath is fainter and slightly tilted, as under earlier hands — hovering or focusing a layer raises it back to legibility. On a post page, the other essays' titles drift behind the text as huge outline ghosts. Old pattern: the scraped-and-rewritten manuscript. New pattern: depth as a CSS custom property (`--depth`) driving opacity/rotation, ghost layers via `-webkit-text-stroke`.
