# v15 — Almanac

The index is one farmer's-almanac ledger table under a double-ruled masthead: date, moon phase (computed deterministically from the date), entry, season ("sowing", "harvest", "deep winter"), and length in words. Column headings are buttons that re-sort the year. Each day's entry opens under a conditions line (`2026-05-12 · 🌖 · sowing · life, thoughts`) with earlier-day/later-day navigation. Old pattern: the almanac's data table. New pattern: client-side sortable columns with `aria-sort`.
