# v12 — Teleprinter

Essays arrive as telegram transmissions: routing headers (`ZCZC MSG 003 · IVRYTWR 20260512 2210Z · VIA LIFE/THOUGHTS`), uppercase subjects, `MESSAGE CONTINUES STOP`, `END OF MESSAGE STOP NNNN`, and a live wire filter (`/` to focus, `Esc` to clear) that narrows the feed as you type. Old pattern: the teletype telegram. New pattern: command-palette-style live filtering over static content.
