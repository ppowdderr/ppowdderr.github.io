# v18 — The Bone Orrery

Essays as moons of carved ivory, held in slow orbit around a dark sun. The index is a working orrery: each ring turns at its own period, each moon rides its rim (counter-rotating so its face stays level), and its starting angle is derived deterministically from the post slug. Below the mechanism, an ephemeris lists the same essays with previews for comfortable reading. Opening a post descends into the moon — a quiet ivory-on-void chamber with an ember drop cap.

Zero dependencies: static HTML, one stylesheet, one script, system fonts only. Same post model as the root site — add a file to `posts/` and one line to `postFiles` in `blog.js`.

Rotation is disabled under `prefers-reduced-motion`.
